MY CREATIVE NOTES — CHROME EXTENSION TEST v8.0.32

This is an unpublished, testable Manifest V3 Chrome extension.
Your existing website is NOT changed by this package.

1. Download and extract this ZIP to a folder.
2. In Chrome go to chrome://extensions
3. Enable Developer mode (top right).
4. Click Load unpacked and select the extracted folder.
5. From Chrome's puzzle-piece icon, pin My Creative Notes.
6. Click the pinned icon to open the app as a full Chrome tab.

Test: Create Tab, double-click tab to edit or delete, Add Note,
edit a note name, save, choose a theme, close and reopen Chrome,
then confirm notes remain. Test Export My Notes and Import My Notes.

Important: The website and Chrome extension have separate storage.
Export your notes from your website (Settings > Export My Notes),
then import that JSON file using the extension's Import My Notes.
Each Chrome browser profile gets its own notes. Back up your notes
before uninstalling the extension. No account or automatic sync.
No requested extension permissions. Not yet on the Chrome Web Store.
